# 🧮 Java Swing Calculator

A desktop application developed using Java Swing as part of the ShadowFox Java Development Internship.

## Features
- Basic Calculator
- Scientific Calculator
- Temperature Converter

## Technologies Used
- Java
- Java Swing
- Visual Studio Code

## Requirements
- JDK 17 (or the version you used)
- Visual Studio Code
- Extension Pack for Java

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Sanjana-2626/Shadowfox_Internship.git
   ```

2. Open the repository in Visual Studio Code.

3. Open the `Task1` folder.

4. Open `Dashboard.java`.

5. Click the **Run** button above the `main()` method
   or run:

   ```bash
   javac *.java
   java Dashboard
   ```
