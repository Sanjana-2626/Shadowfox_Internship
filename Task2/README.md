# 📒 Contact Management System

A desktop application developed using **Java Swing** as part of the **Java Development Internship**. This application allows users to efficiently manage their contacts through an intuitive graphical user interface.

## ✨ Features
- ➕ Add New Contacts
- ✏️ Update Existing Contacts
- ❌ Delete Contacts
- 💾 Save Contacts
- 📋 Display Contact List
- User-friendly Java Swing Interface

## 🛠️ Technologies Used
- Java
- Java Swing
- Visual Studio Code

## 📋 Requirements
- JDK 17 (or the version you used)
- Visual Studio Code
- Extension Pack for Java

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Sanjana-2626/Shadowfox_Internship.git
   ```

2. Open the project in Visual Studio Code.

3. Open the ContactGUI.java file
4. Run the application.
