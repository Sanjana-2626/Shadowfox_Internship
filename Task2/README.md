# Contact Manager (Java Swing)

A desktop application built using **Java Swing** that allows users to manage contacts with full CRUD functionality.

## ✨ Features
- **Add Contacts**: Save new contact details.
- **View Contacts**: Display all saved contacts in a user-friendly interface.
- **Update Contacts**: Edit existing contact information.
- **Delete Contacts**: Remove contacts from the system.

## 🛠️ Tech Stack
- Java
- Swing (GUI framework)
